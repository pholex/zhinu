应用偏好写入工作区所属的 `preferences.json`，使用修订号和状态所有权闸。
旧文件缺桌面快捷键字段时只在读取结果补默认，不触碰文件。保存模型/权限默认值仅影响
之后新建会话；桌面服务端仍校验请求，设置不是新的授权途径。

连接 OAuth 凭据只在服务内存中。内置模型服务商首启输入的 API key 保存到 macOS 钥匙串；
设置页自定义服务商表单仍按用户明确选择写入核心用户 `.env`（0600、只写不回显）。
不能统称“所有凭据仅内存”。模型 key 不进入
桌面偏好、草稿、备份或诊断。密钥表单不自动缓存/重放；重启后需核对实际配置来源。

## 页面与入口

设置采用独立主页面：左侧分类与搜索，右侧分组配置项；保留返回工作区的路径，
不丢失任务、输入草稿和右侧标签页。侧栏底部与应用菜单进入同一页面，提供设置快捷键。
当前搜索覆盖分类、说明和别名；定位到具体设置行、直达链接与滚动位置恢复仍是后续目标。

## 设置的作用范围与持久化

- 应用偏好由羽案应用状态保存；项目配置保留项目归属；模型、工具、权限和沙箱
  继续使用 core/SDK 的真实配置和校验，不能让 GUI 另造更高优先级的隐藏配置。
- 每项展示有效值、配置来源和写入目标。配置优先级遵循 `docs/configuration.md`；
  被环境变量或其他高优先级配置覆盖时，即使保存成功也不能宣称运行值已改变。
- 区分“提供一个可选模式”“设为新会话默认模式”“当前会话已采用此模式”。
  保存默认权限不自动修改运行中的任务，不恢复一次性审批或临时授权。
- 标注即时生效、新会话生效、需重连或需重启；保存失败保留输入并给出真实原因，
  不先把 UI 显示为成功。运行期间不允许变更的设置明确等待空闲边界。
- 连接授权与模型服务商密钥分别处理：前者仅内存、重启重新授权；后者由用户显式保存至系统钥匙串或核心用户配置（各入口明确标注）。
  不提供统一凭据保险库，不承诺连接重启免授权；导出和诊断不包含密钥。
- 元数据保存遵守既有独占所有权和修订号核对；多窗口修改冲突可见，不静默覆盖。

## 实施与验收

框架、分类表和上述已交付设置已接入；长期规划继续逐项实现。声明表描述分类、名称、范围、
读取/写入适配、生效时机、能力条件与搜索词；核心值从真实接口获取。
设置搜索、导航、预留状态从同一份声明渲染，权限规则仍以核心为事实源。

已交付功能的验收覆盖：分类搜索定位、返回草稿、设置持久化、恢复默认、失败保留输入、被覆盖值提示、
多窗口冲突、权限默认值与当前执行分离、导出脱敏。涉及权限、工具和会话的实现按
仓库要求运行全量回归；最终自动验证见 VALIDATION.md，真实系统权限/账号授权和手工使用仍待验收。

静态研究可以证明页面实现、配置调用或本地桥接存在，但不能证明当前账号全部可见，
也不能证明所有分支的运行行为。实现前继续以实际能力和原生交互验证补齐这一缺口。
