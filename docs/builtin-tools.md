# 文件工具与后台事件

## 多文件补丁

`apply_patch` 接收 `changes` 数组，每项只有一个文件，最多 50 项：

```json
{"changes":[
  {"path":"src/example.py","operation":"update","diff":"@@ -1 +1 @@\n-old = 1\n+new = 2\n"},
  {"path":"note.txt","operation":"create","diff":"@@ -0,0 +1 @@\n+hello\n"},
  {"path":"obsolete.txt","operation":"delete"}
]}
```

`diff` 是不带 `---` / `+++` 文件头的 unified diff。hunk 的行号、行数和
上下文必须精确匹配；不猜测位置。末行没有换行时，使用标准的
`\ No newline at end of file` 标记。一次调用不能重复指定同一文件，符号链接
别名也算重复；不支持移动文件。

修改已有文件前先 `read_file`，删除要完整读过；读后版本变化则拒绝。保留已有
文件编码与换行。全部补丁先校验，通过后逐个落盘；这不是多文件事务，I/O 失败
时返回已完成、失败和未执行清单，不要盲目重发整批。update 跟随符号链接更新目标内容；
create/delete 拒绝末级符号链接（包括断链），不会创建或删除其目标。需要操作链接本身时用
显式的 shell 命令；这类操作不参与文件回滚。普通文件改动参与 `/rewind`，回退恢复文件内容，不保证恢复
删除前的权限位等元数据。

### 批量精确替换

更新文件也可用 `edits` 代替 `diff`，无需计算行号：

```json
{"changes":[
  {"path":"a.py","operation":"update","edits":[
    {"old_str":"name = 'old'","new_str":"name = 'new'"},
    {"old_str":"count = 1","new_str":"count = 2"}
  ]},
  {"path":"b.py","operation":"update","edits":[
    {"old_str":"enabled = False","new_str":"enabled = True"}
  ]}
]}
```

每个文件最多 100 处替换。所有 `old_str` 都在该文件的**同一份原文**里匹配，
必须非空、唯一、互不重叠；不会拿前一处替换后的内容去匹配下一处。
不使用模糊匹配，多行替换须从行首开始并带上缩进。`edits` 仅用于 `update`，
不能与 `diff` 同传。沿用补丁的整批预检、逐路径审批、编码换行保留、产物和回退。

## 本地图片

`view_image` 把本地 PNG/JPEG/GIF/WEBP 交给模型，原图读取无需额外依赖：

```json
{"path":"screenshot.png"}
{"path":"screenshot.png","crop":[100,200,900,600],"max_size":1600}
```

裁剪与缩放需 `pip install 'xiaoyu-agent[image]'`。坐标是原始像素的
`[左,上,右,下]`（右、下不包含），先裁剪再按最长边等比缩小，不放大；
`max_size` 为 1–4096。不会隐式旋转 EXIF，动画变换取第一帧。
原文件不变，生成图进入已有媒体缓存，并沿用模型视觉能力检查与代读配置。
源文件最多 7 MiB，变换最多 4000 万像素，输出受媒体大小上限约束；
越界路径沿用读取审批。无视觉能力且未配置代读时不会声称已经看见图片。

## PDF 文字与页面图

安装可选依赖：

```sh
pip install 'xiaoyu-agent[pdf]'
```

`read_document` 始终可发现，未安装依赖时返回安装指引。

```json
{"path":"report.pdf","pages":"1-3,5","mode":"text"}
{"path":"report.pdf","pages":"2","mode":"image"}
```

默认第 1 页、文字模式。文字模式最多 20 页，保留页码；无文字时提示改用图片。
图片模式最多 4 页，彩色页面长边不超过 2000 像素，图片按请求页序交给模型。
单文件最多 50 MiB，单次文字最多 200000 字符；长输出沿用 `recall`。
扫描页不会自动 OCR，文字提取也不承诺复原复杂表格布局；图表和排版请看页面图。
加密 PDF 需要先由用户解密，工具没有密码参数。当前仅支持 PDF。

### 定位与局部高清读取

长文档先查页数与内嵌目录，再找页、读正文，最后核对相关页面图：

```json
{"path":"report.pdf","mode":"info"}
{"path":"report.pdf","mode":"search","query":"Revenue"}
{"path":"report.pdf","mode":"search","query":"Revenue","pages":"101-200"}
{"path":"report.pdf","mode":"image","pages":"12","crop":[0.1,0.2,0.9,0.6],"dpi":300}
```

`info` 返回总页数和 PDF 内嵌书签目录（最多 200 项、15 层），没有书签时明确提示，
不会从正文猜测目录。返回页码均为从 1 开始的物理页码，不是页面上印刷的页码。

`search` 需要非空 `query`（最多 200 字符），按区分大小写的字面文本查找，不支持
正则。省略 `pages` 时搜索前 100 页；指定范围时每次最多 100 页。返回命中页码及
每页首处匹配附近的片段，不输出整页。每页最多搜索前 200000 字符，截断或未搜索
全文时明确提示。扫描页、图内文字及提取时被拆开的词可能漏检，未命中不代表不存在。

图片模式的 `crop` 为左上角原点的归一化 `[左,上,右,下]`，取值 0–1，右大于左、
下大于上；相对于页面当前显示方向。`dpi` 为 36–600 的整数，默认 144（标准 PDF
单位为 1/72 英寸；非标准 UserUnit 不保证对应物理 DPI）。先按区域直接渲染，
不放大低清页面截图。指定 `crop` 或 `dpi` 后输出长边最多 4096 像素，超过时降低
渲染比例；未指定时保持原有长边 2000 像素上限。返回实际图片尺寸。

文字提取即使成功，也可能遗漏图表或打乱表格、双栏顺序。工具描述与文字结果均提示：
涉及图表、排版或关键数值时，用 `image` 核对原页；小字使用局部高清读取。

## Word 正文与结构

安装 `pip install 'xiaoyu-agent[docx]'` 后，`read_document` 也可读取 `.docx`：

```json
{"path":"report.docx","mode":"info"}
{"path":"report.docx","offset":1,"limit":50}
{"path":"report.docx","mode":"search","query":"收入","offset":51,"limit":50}
```

`info` 返回正文块数与使用标准标题样式的标题（最多 200 项）。`text` 默认从第 1 块
读 50 块；`offset` 为起始块号，`limit` 为 1–100。段落和顶层表格保持正文顺序，
未展开的正文结构保留占位块。块号对未改变的文件稳定，不是排版页码。
`search` 在指定块范围内做区分大小写的字面匹配，`query` 最多 200 字符，返回命中
块号和附近片段。后续正文需按提示用 offset 继续；没有命中不代表全文不存在。

每块提取文字最多 20000 字符；每表最多 100 行、每行 50 个物理单元格，
每格最多 2000 字符。合并跨度与纵向合并标记另列，不把合并格展开为重复值。
单次正文输出最多 200000 字符，正文超过 10000 块的文档需先拆分。
截断均有提示；搜索同样受上述提取上限约束。

读取普通正文、表格与超链接文字，不访问链接。图片、批注、修订、文本框、页眉页脚、
脚注尾注会尽可能检测并提示，但其内容不展开；嵌套表格不展开，字段不重算，
自动编号与版面不保证还原。带修订的正文不是“接受全部修订”后的完整定稿。
不支持 DOCX 的 `pages`、`crop`、`dpi` 或 `mode=image`；需要核对排版时先转 PDF。
旧版 `.doc` 需先另存为 `.docx`。

## Excel 工作表与区域

安装 `pip install 'xiaoyu-agent[spreadsheet]'` 后，使用 `read_spreadsheet`：

```json
{"path":"report.xlsx"}
{"path":"report.xlsx","sheet":"收入"}
{"path":"report.xlsx","sheet":"收入","cell_range":"A1:F50"}
```

省略 `sheet` 列出前 100 个页签的名称、隐藏状态和声明范围；声明范围可能包含空白、
样式区域，也可能由导出软件写错，不能视为精确的数据行数。指定 `sheet` 查看该表
合并区域和隐藏行列；分别显示总数，最多列 100 个合并范围、200 个隐藏行、200 个
隐藏列区间。图表页仅列名称，不作为单元格表读取。

同时指定 `sheet` 与 `cell_range` 读取区域，支持 `A1` 或 `A1:F50`，不支持整行整列，
每次最多 2000 格。输出保留坐标、数字/文本/日期/布尔/错误/空白类型与数字格式；
隐藏格仍包含，合并格通常仅左上角有值。文本和公式每格最多 2000 字符，单次单元格
输出最多 200000 字符，截断时提示缩小范围重读。空白不转换成 0。

公式用 `formula` 返回原文，`cached` 单列文件保存的结果：
`cache_status=saved_unverified` 表示保存过但未经本次验证；`missing_or_blank`
表示缓存缺失或为空。**不重算公式，缓存可能过期**；不更新外部链接、不执行宏。
数字保留底层值，`number_format` 只是格式提示，不冒充应用中的渲染结果。
图表、图片和批注内容不读取。当前仅支持 `.xlsx`，`.xls` / `.xlsb` / `.xlsm`
需先另存为 `.xlsx`；CSV、TSV、Markdown 继续用 `read_file`。

两种办公格式均只读，不修改源文件，不解压到工作区。文件最多 50 MiB，ZIP 最多
10000 项、每项最多 20 MiB、总展开量最多 100 MiB，拒绝重复条目、加密条目和 XML DTD。
缺少可选依赖时工具仍可发现并给出安装指引。沿用路径审批、外部内容标注和 `recall`。

## 交互任务

```json
{"command":"python -u -i","interactive":true,"tty":true}
```

`bash` 返回 task ID；`interactive=true` 已包含后台运行，无须另外指定
`run_in_background`。普通输入管道支持各平台；`tty=true` 需要 POSIX 平台，
分配独立伪终端，适合需要 `isatty()` 的 REPL。不会接管用户输入终端，且不承诺
完整交互 shell 的作业控制。Windows 使用普通管道。

```json
{"task_id":"task-1","text":"print(1 + 2)\n"}
{"task_ids":["task-1"],"timeout":1}
{"task_id":"task-1","text":"","eof":true}
```

以上分别调用 `task_input`、`task_output`、`task_input`。输入原样发送，不自动
补换行；每次最多 4096 UTF-8 字节。EOF 后不再接受普通输入；伪终端 EOF 为
终端控制字符，程序是否退出取决于终端模式和程序自身。
POSIX 上单独发送 `"\u0003"` 给任务进程组发中断信号；彻底结束用 `kill_task`。
输入阻塞会有界返回，管道写阻塞超时则终止任务，并提示部分输入可能已送达。

启动交互任务和每次输入都明确审批，密码和密钥不走模型。`--unattended` 可用于
隔离的无人值守环境。任务只属于当前会话进程，结束会话会回收，resume 不能接回
旧进程。普通后台命令仍默认关闭 stdin，行为不变。

## 等待事件

`wait_for_event` 等待当前会话中的后台任务完成、monitor 通知或协作消息：

```json
{"timeout":60}
```

默认 60 秒，范围 0–600；0 仅检查。有尚未送达的事件立即返回，用户插话或取消
会提前结束。通知内容仍经工具结果送达，协作消息和插话仍在工具批次结束的边界
送达，不重复投递或冒充用户输入。`wake=false` 的公告不会唤醒等待。

这个工具不启动任务、不自动重试、不等待已经送达的旧事件。超时后可以继续工作；
要查具体任务的状态和日志用 `task_output`。进程重启后不能等旧后台任务。
