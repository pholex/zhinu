# 0.75.0（2026-10-24）

自 v0.74.0 以来的变化。

## 行为变化（升级前看一眼）

- 配了 DEEPSEEK_API_KEY 的会话多一个 web_fetch 工具，模型可按 URL 读网页原文， 每次成功抓取由 DeepSeek 按次计费（不计入模型 token 用量）；XIAOYU_ENABLE_WEB_FETCH=0 关闭。（6f32a1f）
- agents/*.toml 的 tools 可以写 web_search / web_fetch；宸枢 survey 成员在主会话 配了对应 key 时自动带联网搜索与网页抓取。没点名的 spec 与 build/reviewer 成员行为不变。（f35ce57）
- XIAOYU_SEARCH_PROVIDER=bedrock 时搜索模型由 openai.gpt-5.6-luna 换为 openai.gpt-6-luna， 调用方式、权限要求不变。（a82f313）
- XIAOYU_SEARCH_PROVIDER=deepseek-search（或会话内 /search deepseek-search）时， web_search 返回原始结果列表而非模型结论，按成功请求次数计费、不计 token；web_search 多了 可选参数 count。默认后端不变。（5955a67）
- Deep Research 任务完成后小羽会自动通知模型并在空闲时打一行提示，不再需要用户手动催问；报告不再丢失首段与来源。 bash 工具的 timeout 参数最高 600 秒，更久的命令请用 run_in_background。 后台命令 / monitor 结束时，交互界面空闲也会打一行提示。（d0b6875）
- Deep Research 报告里的图表会保存到用户配置目录 deep-research/<任务 ID>/ 下，正文给出路径，并附给当前模型查看。（a066d61）

## 变化

- 新增：新增 web_fetch 网页抓取工具（6f32a1f）
- 新增：子 agent 与宸枢 survey 成员可按声明使用联网只读件（f35ce57）
- 新增：新增 deepseek-search 裸检索后端，不经模型直接返回结果列表（5955a67）
- 新增：研究报告附图落盘并交给模型看，不再只报数量（a066d61）
- 修复：研究任务完成改为后台通知，模型不再在本轮里 sleep 死等（d0b6875）
- 工程：Bedrock 搜索后端换代 openai.gpt-6-luna（a82f313）
