# 0.65.0（2026-10-06）

自 v0.64.0 以来的变化。

## 新功能

- **`xiaoyu term install`：一条命令把小羽接进 shell**——以前接入 `@x` / `@c` 要自己把 `eval "$(xiaoyu term init zsh)"` 贴进 `~/.zshrc`：找对文件、写对引号、别重复加，要 Tab 补全还得另贴一行、zsh 还得先 `compinit`。现在 `xiaoyu term install` 按 `$SHELL` 认出 zsh / bash / fish，先打出要写哪个文件、写哪几行，确认后才写（`--yes` 跳过确认，`--dry-run` 只看不写），写前留 `.bak`。写进去的是首尾带标记的一段，包含终端集成和 Tab 补全两样：zsh 前置一行带守卫的 `compinit`（oh-my-zsh 之类已经初始化过就跳过）；不要补全加 `--no-completion`。选项与 `term init` 相同（`--natural`、`--name`、`--command-not-found`），换选项重跑只替换这一段，不会重复加。`xiaoyu term uninstall` 移除。
- **按平台写对文件**——macOS 上 bash 写 `~/.bash_profile`（系统终端开的是登录 shell，不读 `.bashrc`），Linux 与 Windows 的 Git Bash 写 `~/.bashrc`，zsh 认 `$ZDOTDIR`。读写保留文件原有的换行符，不往启动文件里混进 `\r\n`。PowerShell 不自动写：`$PROFILE` 的位置随版本而变，照文档手动贴一行。`PATH` 上找不到 `xiaoyu` 命令时只写终端集成、不写补全，并说明原因。
- **不动你自己写的配置**——启动文件里已经有手写的 `term init` 那一行，install 原样不动、只提示；缺补全时列出要加在它前面的几行。标记段被改坏了也不碰。
- **`xiaoyu doctor` 报告终端集成**——新增 `shell` 一项：当前终端接没接上、哪个启动文件写了、Tab 补全有没有；没接入不算异常，只指路。
- **在 agent 会话里运行时指回你自己的终端**——`term install` / `term uninstall` / `terminal-setup` 改的是个人配置，要本人确认。被 agent 在工具里调用时读不到确认、或写家目录被沙箱拒绝，以前只回一句「没有改动」或一行错误码，模型看不出原因；现在说明原因，并给出原样的命令请你在自己的终端里运行。
- **`xiaoyu update` / `xiaoyu uninstall` 连同嵌入 SDK 一起处理**——SDK（`xiaoyu-agent-sdk`）精确钉住同版本的本体：以前 update 只升本体，SDK 的版本约束随即对不上；uninstall 只卸本体，剩下一个一导入就报错的 SDK。现在检测到同一环境装了 SDK，就把它一并交给 pip。README 的安装命令也带上了 SDK。

## 修复

- **`doctor` 的 Python 版本下限对齐包声明**——包要求 Python 3.11+，`doctor` 却按 3.10 判断。实际不出错（3.10 装不上包），但下限只该有一个数，现在由测试对账。

## 行为变化（升级前看一眼）

- **`xiaoyu uninstall` 多做两件事**——会移除 `term install` 写进启动文件的那一段（留 `.bak`），装了 SDK 时一并卸掉 SDK。卸载前照常先列出计划、确认后才动手。
- **`xiaoyu update` 会一并升级已装的 SDK**——没装 SDK 的环境不受影响。
- **`doctor` 多一项 `shell`**——用 `--json` 解析结果的脚本会看到多出的这一项。

## 文档

- `xiaoyu --help` 里 `term` 一行点出 `term install`，`completion` 一行注明 install 会一并写好。
- 终端集成文档的安装一节改为先推荐 `term install`，补了各平台写哪个文件、补全怎么接的对照表；README 同步。
- SDK README 补安装说明（pip 会按精确版本自动带上本体，不必另起 CLI 或 serve；凭据只经 `ModelOptions` 传入，不读 `.env`）与单次调用加多轮会话的上手示例；示例目录改为按 PyPI 安装。
- SDK 验收记录里写于 0.59.0 发版前的「尚未发布」改注为已随 0.59.0 发布。

## 工程

- 新增测试对账 `doctor` 的版本下限与 `pyproject.toml` 的 `requires-python`。
- `term install` 的测试读写一律按 UTF-8、不再改 `os.name`（前者让 Windows 按 cp1252 解码失败，后者让 Python 3.11 的 pathlib 建不出路径对象）。
- ACP 注册表条目固定到 0.65.0。
