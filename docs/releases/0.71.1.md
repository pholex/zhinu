# 0.71.1（2026-10-14）

自 v0.71.0 以来的变化。

## 工程

- 升级模型接口依赖：openai 3.24.0 → 3.28.0、anthropic 1.11.0 → 1.13.0。
- 升级 Bedrock 可选依赖：boto3 / botocore 1.43.108 → 1.43.111。
- 升级 HTTP 服务可选依赖：FastAPI 0.142.2 → 0.143.0。
- 为异步问答测试预留线程调度与存储等待余量，避免 Windows 全量测试因过短的等待时限误报失败。

## 行为变化（升级前看一眼）

- 安装或升级本版时会使用上述锁定版本；Bedrock 与 HTTP 服务依赖仍通过对应可选安装项启用。
- 本版为依赖维护更新，命令、配置项和公开 API 保持兼容。
