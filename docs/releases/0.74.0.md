# 0.74.0（2026-10-16）

自 v0.73.1 以来的变化。

## 行为变化（升级前看一眼）

- 启用会话持久化后，文件工具检查点可在同工作区重启恢复；会话日志会保存编辑前原始内容的 Base64 备份。 SDK、HTTP 和 CLI JSON 可取得本轮文件产物清单，非空时发布 artifacts.ready 事件。（d977366）
- /rewind 与 /undo 选择范围后先展示预览，再以默认否确认；取消会保留文件和对话。 增加 --preview 只读查看入口；SDK 可通过 preview_rewind 获取预览并交回 rewind 校验后执行。（1a95133）
- /context 展示本次运行项目指令的来源、加载状态与正文截断数量，查看时不重读磁盘；/clear 后子目录指令可以重新加载。（265d064）
- 自动降级提示按实际原因展示；sessions inspect --kind model 可查看切换经过，--errors 包含故障触发的切换，手动切换和首选恢复不标为错误。（59b880b）
