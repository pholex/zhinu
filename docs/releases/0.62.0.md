# 0.62.0（2026-10-05）

自 v0.61.1 以来的变化。

## 新功能

- **SDK：宿主交互与持久化问答首版**——`xiaoyu-agent-sdk` 新增宿主提问回调（`asker`）、类型化文字／图片输入、运行中插话（`steer`）、通知与状态快照、会话控制（重置、切模式、换模型、token 软预算）、可选计划工具和工具结果文本变换（`result_transforms`）。持久化问答让模型提出的问题可以稍后回答：关闭、重启、断线重连之后，宿主仍能查询问题、提交回答并查证它是否已进入会话历史。`xiaoyu serve` 提供同一套问答的 HTTP 入口（创建会话时传 `questions` 开启）。见 `docs/sdk.md`、`docs/sdk-deferred-questions.md`、`docs/serve-questions.md`。
- **联网搜索多后端**——`web_search` 可选 `deepseek`、`xai`、`bedrock` 三个后端，会话内用 `/search` 查看各后端的配置状态并切换（只影响当前会话）。新增两个独立工具：`x_search` 搜索 X 平台的帖子、用户与讨论串（需 `XAI_API_KEY`）；`deep_research` 提交 Gemini 后台研究任务，配套 `deep_research_status` 查询进度与报告、`deep_research_cancel` 取消（需 Gemini key）。见 `docs/configuration.md`。
- **工具参数生成进度**——模型在生成很长的工具参数时，界面和嵌入事件会给出有界预览（已闭合的路径与目的、累计字符数），不再像卡住了一样；审批与执行仍只使用收齐后的完整参数。嵌入方对应新事件 `ToolPreparing`（`tool.preparing`）。
- **会话时间线诊断**——`xiaoyu sessions inspect` 只读扫描会话日志，按行号、请求、工具调用筛选，列出失败请求、非零退出码、拒绝与损坏记录；支持 `--json`，展示前脱敏。见 `docs/session-inspection.md`。
- **终端集成 `@x` 更好问**——zsh 下问题里的 `?` `*` `[` 不再被当成通配符（此前以半角问号结尾的问题会直接报 `no matches found`）；只敲 `@x` 回车会出现「问 ›」提示符，在那里输入的问题原样读入，括号、引号、管道符都不必转义。交给模型的终端上下文现在带上每条命令的退出码，「刚才那条为什么失败」可以直接问。见 `docs/terminal-integration.md`。
- **Gemini Flash 直连预设更新为 `gemini-3.8-flash`**，并补齐上下文窗口映射。

## 行为变化（升级前看一眼）

- **`web_search` 的默认后端从 xai 改为 deepseek**——只配了 `XAI_API_KEY`、没有 `DEEPSEEK_API_KEY` 的环境，升级后 `web_search` 不再挂载（选中的后端没配置时不会自动改走别家）。要保持原行为，设 `XIAOYU_SEARCH_PROVIDER=xai`。
- **`x_search` 与 `deep_research` 默认开启**——配了对应 key 就会出现在工具列表里，两者都在模型 token 之外另行计费。不需要时设 `XIAOYU_ENABLE_X_SEARCH=0` / `XIAOYU_ENABLE_DEEP_RESEARCH=0`。检索子 agent 与评测默认不启用它们。
- **Gemini 直连预设不再包含 `gemini-3.7-flash`**——配置里按名字写死旧型号的，改成 `gemini-3.8-flash`。
- **终端集成要开新终端才生效**——已经开着的终端里加载的还是旧版钩子：`@x` 照常能用，但没有退出码，zsh 下也还没有通配符保护。zsh 的 `@x` 从函数改成了别名，`setopt no_aliases` 的环境改调 `__xiaoyu_term_ask`。
- **不带问题的 `@x` 不再报错**——stdin 是终端时改为等待输入一行；管道与脚本里（stdin 不是终端）仍按原样报「要问什么」。
- **pending 文件多了状态行**——每条命令跑完后追加一行 `=<开跑时刻>\t<退出码>`。旧版写的文件照常能读；上限从 500 行改为 500 条命令。
- **嵌入事件新增 `ToolPreparing`**——只增不改，老消费方不受影响；收到 `request.ended` 后应清掉该请求的全部预览。
- **持久化问答的日志不向下兼容**——启用问答后写下的会话记录，旧版本无法正确恢复；内核与 SDK 请使用同为 0.62.0 或更新的匹配版本。

## 修复

- **URL 里的凭据完整遮蔽**——访问令牌只占用户名字段、或密码里含多个分隔符时，终端展示也会完整隐藏。
- **技能来源去重**——同一技能经家目录或符号链接被重复扫描时，不再出现虚假的撞名提示；不同插件命名空间的技能仍各自可见。
- **bash 终端集成**：原有 `PROMPT_COMMAND` 以分号结尾时，拼接后不再是语法错。

## 工程

- SDK 的 CI 显式安装同一次构建出的内核与 SDK 两个包，避免装到索引上的旧内核。
- ACP 注册表条目固定到 0.62.0。
