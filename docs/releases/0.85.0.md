# 0.85.0（2026-11-17）

自 v0.84.0 以来的变化。

## 行为变化（升级前看一眼）

- macOS 上装好 ~/Applications/Xiaoyu Computer Use.app 后，会话多一个 computer_use 工具， 模型可经审批读取并操作本机应用界面；XIAOYU_ENABLE_COMPUTER_USE=0 关闭。其它平台无变化。
- 电脑操作执行时桌面上会出现小羽自己的光标指示落点，可用 defaults 关闭；锁屏下 state 报"屏幕已锁定"而非"没有窗口"。
- 辅助进程空闲 30 分钟自动退出（idleExitMinutes 可关）；XIAOYU_COMPUTER_USE_SOCKET 自定义路径现在真的生效。
- computer_use 多了 paste 与 select_text 两个动作。
- 辅助 app 放在任意位置、只要系统登记过（Spotlight 索引到或启动过一次）就能被找到。
- 装好辅助应用后可用 `build.py --install --link ~/.local/bin` 得到 `xiaoyu-cua` 命令，脱离小羽直接读界面、做动作。
- 升级模型 SDK（openai 3.49.0、anthropic 2.7.0）及 PDF、浏览器、Bedrock、serve 可选依赖。

## 变化

- 新增：新增 computer_use 电脑操作工具与原生辅助进程 Xiaoyu Computer Use.app（实验）
