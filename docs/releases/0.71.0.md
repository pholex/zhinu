# 0.71.0（2026-10-13）

自 v0.70.0 以来的变化。

## 新功能

- HTTP 服务支持 `xiaoyu serve --environment host|sandbox`。普通主机选择 `host`，已有专用隔离容器或虚拟机选择 `sandbox`，无需再组合环境变量与审批参数。（6118e05）

## 修复

- 输入后续建议的编号时，交互界面会展开并回显对应正文，模型能直接执行选中的建议。（919e2fa）
- macOS auto 档下，系统 `ps`、允许联网时的 `traceroute` / `traceroute6`，以及单条有限次 `top` 查询不再反复要求沙箱升权。`top` 仅放行通过完整参数校验的查询；`ps` 管道中的其他命令和重定向仍受沙箱约束。（5ad068b）
- 升级模型与 HTTP 服务依赖：openai 3.24.0、anthropic 1.11.0、boto3 / botocore 1.43.108、FastAPI 0.142.2、websockets 17.2。修复新版跨源中间件重复拒绝已按来源白名单放行的私有网络预检，其余来源、请求头和鉴权校验保持有效。（ae45df4）

## 行为变化（升级前看一眼）

- 显式指定 `--environment host` 会开启内部命令沙箱，审批默认 `ask`；不传环境参数时继续兼容原有沙箱环境变量配置。
- `--environment sandbox` 声明服务已有外部隔离，关闭内部命令沙箱，审批默认 `allow_all`。此参数不会创建或验证容器，写入和网络限制由外部隔离承担；浏览器、MCP 及显式 ask 规则触发的审批也会被自动批准。需要保留人工审批时加 `--approval ask`。token 鉴权、deny 规则和其它护栏保持原配置。
- 其它沙箱升权仍只批准本次，确认框不再提供「本会话允许」或「总是允许」选项，以免误解为后续命令已经获准。
