# 0.61.1（2026-10-02）

自 v0.61.0 以来的变化。

## 修复

- 升级模型 SDK 后，本地模型仍直接连接，远端请求继续遵守代理与 `NO_PROXY` 配置，连接和读取超时分别生效。
- 修复 Bedrock 流内异常在新版 SDK 下被误判为不可恢复的问题；服务端流错误可重试，请求校验错误仍停止。
- 模型列表探测遇到没有错误文本的异常时，显示异常类型并跳过该端点，启动不再因二次异常中断。

## 依赖更新

- OpenAI SDK 2.52.0 → 3.23.0、Anthropic SDK 0.121.0 → 1.9.0，模型传输与独立 SDK 的 HTTP 请求统一迁移到 `httpx2`。
- Rich 14.3.4 → 15.0.0、Playwright 1.62.0 → 1.63.0、Uvicorn 0.52.3 → 0.54.0。
- SOCKS 支持的安装命令更新为 `pip install 'httpx2[socks]'`。

## 兼容性

- Python 最低版本保持 3.11，公开 API 不变。
- 可选浏览器功能使用的 Playwright 1.63 不再支持 Ubuntu 20.04；使用该功能的环境需升级到受支持的系统。
