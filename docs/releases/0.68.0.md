# 0.68.0（2026-10-08）

自 v0.67.0 以来的变化。这一版集中在终端交互：正文着色、输入行建议、会话选择器过滤、放行编辑的 diff 回显，外加 `sudo` 要密码的通道。

## 新功能

- **`sudo` 要密码时在界面里向你要**——bash 工具起的命令没有控制终端，`sudo` 读不到 tty 直接失败，以前这类命令只能自己开终端敲。现在走 `sudo` 自带的 askpass 机制：TUI 弹遮罩输入框、明文 REPL 用 getpass 向你要一次，密码只在内存里交给 `sudo`，不落盘、不进会话记录、不出现在工具输出里，模型看不见。沙箱里 setuid 程序起不来，所以它实际配合 `danger-full-access` 升权（仍必问）或 `XIAOYU_SANDBOX=0` 才起作用；无人值守（`-p` / serve / ACP / 子 agent）不装，`sudo` 照旧报需要终端。问密码的时间不算进命令超时。`XIAOYU_ENABLE_ASKPASS=0` 关。
- **正文行级轻渲染**——代码围栏内按语言语法着色（围栏线弱化），围栏外的行内 `` `代码` ``、`**粗体**`、`#` 标题各自变色。每个字符仍只打一次、不重绘，滚出屏幕的内容与当时看到的一致；标记符保留原样只弱化，复制出去与模型原文逐字一致；代码块里的 tab 原样保留。配色跟随深浅主题。管道、`-p`、CI 下仍是纯文本。
- **`/resume` 会话选择器敲字过滤**——菜单顶部多一行过滤串，敲字即按词过滤（空格分词、每个词都命中、不分大小写），Backspace 删字；敲 `0810` 能命中显示为 `2026-08-10` 的会话。一次只显示 10 行，更多的提示「还有 N 个」，选中项超出时整窗跟着滚。列表上限从 9 放到 30。明文 REPL 的编号输入同一条规则：敲的不是数字就当过滤词缩小列表再问。`xiaoyu resume` 子命令的菜单一并生效。
- **放行的编辑也看得到改了什么**——auto、`--yolo` 和 allow 规则放行的 `write_file` / `str_replace`，完成行带 `+N −M`，diff 折叠进留底（Ctrl-O 回放带红绿；详情模式开着直接展开）。走确认框的编辑预览已经在屏上，不重复补。
- **每轮答完给出「接着问」**——轮结束后另起一个旁路小请求给辅助模型（`summary_model`，默认便宜模型），从本轮一问一答提最多 3 条短句：回答下方打一行「接着问：① ② ③」，输入行空着时灰字浮现第一条、行尾 `→` 接受，敲几个字按前缀选其它条；只预填，绝不自动发送。旁路请求不进历史、不占上下文，失败静默。`-p` 默认不做，`--suggestions` 才算进结果；serve / ACP / SDK 宿主默认关。`XIAOYU_SUGGESTIONS=0` 关。
- **输入行按历史给灰字建议**——敲到一半浮现最近一条同前缀的历史（敲 `! brew` 浮出上次的 `! brew upgrade …`），光标在行尾按 `→` 或 `Ctrl-E` / `Ctrl-F` 接受，与 shell 的自动建议同一直觉。
- **输入行行首的 `!` / `/` / `#` 着色**——一眼看出这一行是直接跑 shell、斜杠命令还是备忘；只敲了前缀还没正文时颜色就亮，深浅主题各自跟随。

## 修复

- **确认框的 diff 预览有界**——新旧两边行数之和超过 1500 行不再跑逐行比对（相似的大文本上是平方级，确认框会卡在算 diff 上没有回显），改按全删 / 全增给出并标注「未逐行比对」，仍完整、仍可 Ctrl-O 看全文。
- **`/resume` 的列表以前凑不够上限**——先被默认的 20 条截了一刀再剔当前会话。
- **发版不再因 PyPI 索引延迟而失败**——上传后等 pip 读的 `/simple/` 索引更新再装回验证，装不到时重试。
- **Windows 下 CRLF 文件的编辑 diff 误报整文件改动**——比内容不比换行符。

## 行为变化（升级前看一眼）

- **模型正文带 ANSI 着色**——只在真终端上；管道、`-p`、CI 不变。拿终端 scrollback 做文本处理的人会看到样式码（`NO_COLOR` 照常生效）。
- **`/resume` 菜单里的数字不再直选**——数字进过滤串；直选用 `/resume <序号>`，序号沿用列表编号、过滤后不变。
- **交互前端每轮默认多一次辅助模型请求**（「接着问」建议，算在 `summary_model` 名下）——`XIAOYU_SUGGESTIONS=0` 关；一次性模式与宿主集成默认不发。
- **放行的编辑完成行变长**——多出 `+N −M` 与「还有 N 行」；原来折叠在后面的「改动后该处上下文」几行被 diff 顶掉（那几行仍回灌给模型）。
- **`sudo` 要密码会在界面里问你**——`XIAOYU_ENABLE_ASKPASS=0` 回到以前「报需要终端」的行为。
