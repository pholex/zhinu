# 0.87.0（2026-11-22）

自 v0.86.0 以来的变化。

## 行为变化（升级前看一眼）

- 交互界面默认换成常驻输入区（macOS / Linux）：输入框与底部状态行一直显示，作答中 Esc 是打断本轮，不再是清空草稿；底部提示写「esc 打断」，Ctrl-C 仍可打断。想用原来的样式加 --classic，或设 XIAOYU_LIVE_INPUT=0 长期生效；Windows 上一律是原来的样式。（65d78e0、f694e24）
- 常驻输入区下调整终端窗口大小会清空该终端此前的滚动历史，只保留小羽本次会话最近 5000 行输出并按新宽度重排。（ccffe13）
- 两种样式下，输入提示符都由 › 改为 ❯；模型回复每段以 ● 开头并缩进两格，区块之间多一个空行；你发出的话在记录里以 ❯ 开头、整段用强调色并带底色（底色只到文字末尾）；轮末耗时一行以 ✻ 开头。（8781696、2fccb30、a86ae3f）
