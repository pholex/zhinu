# ship-fix — 修缺陷并交付

## 步骤

1. **先复现**：跑 `sh run_tests.sh`，确认有用例失败，再动手。
2. **只改 `src/` 下的代码**。测试是对的，不改 `tests/`；不新增测试文件。
3. 再跑 `sh run_tests.sh`，全部通过才算修好。
4. **记一笔**：在 `FIXES.md` 末尾追加一行，格式 `- <改动的文件名>：<一句话说明>`，
   例如 `- stock.py：扣库存时没有检查数量为负`。
5. **开分支提交**：从 main 开分支 `fix/<文件名去掉扩展名>-<两三个英文单词，连字符连接>`，
   在这个分支上提交**一次**，代码改动与 `FIXES.md` 放在同一个提交里。
   提交说明第一行：`fix(<文件名去掉扩展名>): <一句话说明>`。

## 规则

- 不在 main 上提交，不合并回 main，不 push。
- 提交完工作区要是干净的，停在新分支上。
- 收尾时告诉用户分支名和提交 ID。
